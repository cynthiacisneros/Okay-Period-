# Okay, Period! 

Okay, Period! is an educational and supportive web experience designed to help young users better understand menstrual health, body changes, cycle tracking, and emotional wellness in an approachable and beginner-friendly way.

The project was created as a senior capstone focused on combining accessible health education with thoughtful, modern web design.

---

## Project Purpose

Many young people experience confusion, anxiety, or shame surrounding menstruation and body changes due to limited accessible education and stigma. Okay, Period! was created to provide a softer, more supportive introduction to menstrual health through clear language, calming visuals, and easy-to-navigate educational content.

The website aims to:
- Normalize conversations about periods and body literacy
- Encourage cycle awareness and self-understanding
- Provide accessible educational information
- Create a safe and welcoming digital experience for users

### How to Use the Website

Okay, Period! is fully browser-based and requires no installation or account creation.

Users can:
- Navigate through the website using the main navigation menu
- Explore educational sections at their own pace
- Learn about menstrual health and body literacy
- Review cycle tracking recommendations and wellness resources
- Access the website on desktop or mobile devices

- Internet connection
- Modern web browser (Chrome, Safari, Edge, Firefox)
